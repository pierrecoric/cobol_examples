# cobol_examples
Short cobol programs to illustrate the [Open Mainframe Project Cobol Programming Course](https://openmainframeproject.org/projects/cobol-programming-course/)


## 1. HELLO.cbl
[HELLO.cbl](https://github.com/pierrecoric/cobol_examples/blob/main/HELLO.cbl)
Based on chapter 2 of the OMPCPC.
Illustrates the notions of Areas A and B, the four divisions.
COBOL reserved words introduced: DISPLAY and GOBACK.

## 2. DATA1.cbl
[DATA1.cbl](https://github.com/pierrecoric/cobol_examples/blob/main/DATA1.cbl)
Based on chapter 3.
Covers the WORKING-STORAGE SECTION, the picture clause, the MOVE and COMPUTE statements.

## 3. TABLE1.cbl
[TABLE1.cbl](https://github.com/pierrecoric/cobol_examples/blob/main/TABLE1.cbl)
Based on chapter 4.
Goes over a the declaration of a simple table. COBOL reserved words introduced: FILLER, REDEFINES, OCCURS, TIMES, PERFORM (more on perform later).

## 4. FILES1.cbl
[FILES1.cbl](https://github.com/pierrecoric/cobol_examples/blob/main/FILES1.cbl)
Shows how to open an external file and load its data in an internal file.

## 5. PERF1.cbl
[FILES1.cbl](https://github.com/pierrecoric/cobol_examples/blob/main/PERF1.cbl)
Several examples of the use of PERFORM, examples of control flow and paragraphs.
